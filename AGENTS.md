# Repository instructions

- Не добавляй Codex или других ИИ в авторы и соавторы коммитов. Не добавляй `Co-authored-by` и `Generated with Codex`. Используй текущие `user.name` и `user.email` Git.
- Не добавляй и не запускай автоматические тесты в этом репозитории. Это явное предпочтение пользователя.
- Локальная `.atlyss_decompiled/` служит справочником для анализа API и логики ATLYSS. Сохраняй её локально; не добавляй в Git, сборку или архив мода. NuGet GameLibs содержит только ссылки для компиляции, без исходной реализации методов.
